حزمة تثبيت الباحث العقاري من المتصفح

مهم: لا يتم تثبيت التطبيق مباشرة من ملف ZIP. يجب أولاً رفع الملفات إلى موقع يعمل عبر HTTPS (مثل GitHub Pages).

خطوات النشر على GitHub Pages:
1. فك ضغط هذا الملف على جهاز الكمبيوتر.
2. افتح مستودع GitHub الخاص بالمشروع.
3. ارفع الملفات الستة الموجودة داخل الحزمة إلى جذر المستودع، بجانب index.html مباشرة، ووافق على استبدال الملفات عند طلب ذلك.
4. انتظر حتى ينتهي GitHub Pages من النشر.
5. افتح رابط الموقع المنشور في Chrome على الهاتف.
6. من قائمة ⋮ اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» (قد تختلف التسمية حسب المتصفح).

ملاحظات:
- يجب أن يكون الموقع منشوراً عبر HTTPS كي يعمل التثبيت من المتصفح.
- هذه الحزمة تخص واجهة النسخة التجريبية. لا ترفع بيانات حساسة أو سجلات عقارية حقيقية إلى موقع عام.
- لا تستبدل نسخة الموقع الحالية قبل تجربة النسخة الجديدة والتأكد من سلامة الوظائف والبيانات.
